# Ebook Brand

Client web app for **author publishing / Quantum Arc** services — marketing site and flows for publishing a book online.

## Stack
- React 19 + TypeScript + Vite
- TanStack Router / Start
- Three.js / React Three Fiber
- Tailwind CSS + shadcn-style UI
- Built with Lovable

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
